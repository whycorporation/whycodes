# Support

Where to get help with WhyCodes, and what belongs where.

## Using the product

- [README](README.md) — what it is and how to install
- [User guide](docs/guide.md) — CLI, TUI, agents, tools, config, SDK
- [Auth](docs/auth.md) — API keys, OAuth, credential import
- [Packaging](docs/packaging.md) — Homebrew, installers, upgrades

For a TUI problem, the last lines of
`~/.local/share/whycodes/logs/unified.jsonl` are the fastest diagnostic.
See [docs/knowhow.md](docs/knowhow.md) for what the lifecycle events mean.

## Bugs and feature requests

Open a GitHub issue with the command you ran, what you expected, and what
happened. Use the issue templates when they fit.

There is no Discord, forum, or mailing list. GitHub issues are the public
support channel.

## Contributing a change

[CONTRIBUTING.md](CONTRIBUTING.md) is the short path from clone to a merged
change. Behaviour in this repository is also covered by the
[Code of Conduct](CODE_OF_CONDUCT.md).

## Security

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).
